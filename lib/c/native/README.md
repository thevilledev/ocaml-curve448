# C backend

[Documentation](../../../docs/README.md) · [Design](../../../docs/design.md)

The optional `curve448.c` implementation. Everything here is compiled into the
single translation unit `curve448_stubs.c`; all other functions are `static`
and live in headers. The pure OCaml default backend in `lib/ocaml/` shares
none of this code.

| File | Origin | Contents |
| --- | --- | --- |
| `p448_64.h` | fiat-crypto, generated | Field arithmetic modulo 2^448 - 2^224 - 1 |
| `field448.h` | hand-written; wrapper types follow BoringSSL | Typed tight/loose wrappers, constant-time select and swap, inversion and square-root chains |
| `scalar448.h` | hand-written | Arithmetic modulo the edwards448 group order L |
| `shake256.h` | hand-written; round function follows tiny_sha3 | Keccak-f[1600] and SHAKE256 |
| `edwards448.h` | hand-written; point types follow ref10/BoringSSL | Complete edwards448 formulas, point encoding, constant-time scalar multiplication |
| `curve448_tables.h` | generated by `tools/gen_tables.py` | d, the base point, and the fixed-base table |
| `curve448.h` | hand-written; X448 ladder adapted from BoringSSL | X448 and Ed448/Ed448ph |
| `ct.h` | hand-written | Wiping helper |
| `curve448_stubs.c` | hand-written | OCaml bindings and internal test hooks |

## fiat-crypto

`p448_64.h` is `fiat-c/src/p448_solinas_64.c` from
[fiat-crypto](https://github.com/mit-plv/fiat-crypto) release `v0.1.6`,
commit `9d0682462646bf645cba7409fa45794dee0418aa`, copied without
modification (only the file name changed, so dune does not compile it on its
own). SHA-256 of the file:

```
36fd34df22ba8aa7a5e34145c041d15bd04229649c033499ad3d018e9de50f99  p448_64.h
```

Its header records the generator invocation:

```
unsaturated_solinas --inline --static --use-value-barrier p448 64 8 '2^448 - 2^224 - 1' \
  carry_mul carry_square carry add sub opp selectznz to_bytes from_bytes relax
```

fiat-crypto proves that this code computes the specified field operations
within the stated limb bounds. The wrappers in `field448.h` keep tight and
loose elements in distinct C types so that the compiler enforces those bounds.
fiat-crypto is available under the MIT, Apache-2.0 or BSD-1-Clause licence;
this project uses it under MIT, and `licenses/fiat-crypto.txt` holds the
notice and the fiat-crypto authors. The parts adapted from BoringSSL (ISC) and
tiny_sha3 (MIT) are listed with their notices in `licenses/boringssl.txt` and
`licenses/tiny_sha3.txt`.

fiat-crypto's 32-bit p448 output still declares and uses `unsigned __int128`,
so it would not help genuine 32-bit targets and is not vendored. The library
therefore requires a 64-bit GCC or Clang.

The pre-generated fiat output has no multiply-by-small-constant function for
p448 and no code for the scalar field, so the X448 ladder multiplies by
a24 = 39081 with the general multiplication, and `scalar448.h` is hand-written
and tested against Zarith (see `docs/testing.md`).

## Regenerating the tables

```sh
python3 tools/gen_tables.py > lib/c/native/curve448_tables.h
python3 tools/gen_tables.py --check lib/c/native/curve448_tables.h
```

The generator uses Python integers only. The test suite recomputes every
table entry with an independent Zarith model.
